Entry for [The Tired Dark Lord: A 100-Word Villain Monologue](https://make.fun/bounty/u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb) on make.fun.

A ~100-word monologue spoken by a fantasy villain who is secretly just very tired. The tiredness lives in the voice, the rhythm, and the small deflections — the sticking third step, the warm candles, the empty chair opposite — never in a plain statement that he is weary. He still has a scheme (the eclipse gate opens at dusk) and a history (back when the mountain still smoked).

## Run

```sh
python3 main.py   # writes /output/entry.txt
```

Deterministic, offline, standard library only. Two runs produce byte-identical output.
